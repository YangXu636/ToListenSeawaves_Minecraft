# 神谕终端【双蛇杖】

特殊能力：

神谕终端基础为双蛇杖形态，简称基础形态

基础形态下按下右键随机切换为9把武器的任意一种，切换时会有指令的哔哔音效

武器每次攻击有5%的概率切换回基础形态，或在累积造成35点伤害后切换回基础形态

在武器形态按下shift+右键、快捷键（默认为无）变回基础形态，同样有音效

无论是从基础形态变成武器，还是变回，都会导致双蛇杖出现0.8秒的冷却，效果类似于末影珍珠

神谕终端不可被附魔，无法摧毁，伤害与攻击速度按照武器改变
