# **指令【终端】**

简短的介绍：指令终端是极其重要的物品，它会发布指令，当指令完成够多后就可以获得双蛇杖

获得流程：在创建世界时，在出生点的1万格内会生成建筑1，建筑1内有着一个台子，每名玩家可以从中获得一个**指令【终端】**，不可重复，在出生点1万格外会极少概率刷新建筑2，建筑2同样是有一个台子，但建筑2的的台子只能获得一次**指令【终端】**

功能：

1.【终端】在物品栏或副手时，会每隔一段时间发送指令[^1]，发送指令时会有哔哔音效

2.没有指令要求将【终端】丢弃、放置在背包格、箱子等等，算作违反指令，并结束还在持续的指令

3.指令只有在：手持或副手持【终端】才能查看。指令会代替经验条进行显示，并将经验数字改为业

4.指令发送的指令会根据玩家的进度进行变化，目前三个阶段，默认一阶段，进入下界二阶段，进入末地三阶段，每个阶段会解锁新的，难度更高的指令

5.指令最多存在一条，且均有时限，时间到会算作未完成指令，增加1级业[^2]

6.指令发布的间隔会根据上一次被完成的指令的难度决定，越难间隔越长

7.在完成指令时会回复饥饿度，饱食度，生命各3点

8.在手持指令武器时，【终端】会进入战斗形态，每30秒朝着最近的中立、敌方生物发送指令标记[^4]（30秒），不手持则清除指令标记，指令标记只有发布者能看到。

9.【终端】进入三阶段，并完成至少60条指令时，每次完成指令会有10%的概率获得每个终端只能发布一次的指令：获得[神谕终端【双蛇杖】](神谕终端【双蛇杖】.md)

10.哎呦怎么这么多机制啊不写了呵呵呵呵（摸摸）

[^1]: 指令：让你去做某件事，让你不去做某件事，不要疑问


[^2]: 业：最多5级，每多一级会使业图标的一片花瓣变暗，有1级以上的业会在周围刷新代行者[^3]，代行者会主动攻击有业的生物，越多代行者就越多，物种和携带的buff也会变得强大


[^3]: 代行者：可以是任何生物，只是某种代号，只会攻击有业的生物

[^4]: 指令标记：buff，被发布者攻击消失（也只有发布者能看到），消失时给予攻击者回复饥饿度，饱食度，生命各3点。如果持续时间结束还没有攻击那么会对发布者造成缓慢1虚弱1反胃1失明1中毒3，3秒
