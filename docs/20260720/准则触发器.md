# 可用准则触发器

以下准则均默认在`to_listen_seawaves`命名空间下

---

## **any\_block\_use**

玩家与方块进行任何交互（包括默认交互，以及玩家不空手使用物品等方式）时触发。可用条件：

[思维导图-a4f39824380f446b82a68adbc1e9b259](#r4WqmFa20w9mSw1z9HxUpc)

| 战利品上下文参数 | \[\]  location |
| :--- | :--- |
| origin | 交互的方块的中心位置 |
| this\_entity | 玩家 |
| block\_state | 交互的方块的方块状态 |
| tool | 交互时所使用的物品 |

---

---

## **player\_hurt\_entity**

玩家伤害实体（包括自己）时触发。可用条件：

[思维导图-7ff5d34b48be421a8e19dc10c0d35e09](#NvZTxy9xsJQaJPJWT5sNBa)

| 战利品上下文参数 | \[\]  entity |
| --- | --- |
| origin | 玩家位置 |
| entity | 被伤害的实体 |

---

## player\_movement

每游戏刻对所有玩家触发一次。其中，位移按单方向累计，反向移动时累计距离先归零再累计。

可用条件：

[思维导图-2d7a2b23f9804e25bc3923e928a1a55a](#TNbls1rY4hDSCxWqs3ai0F)

---

## player\_rotation

每游戏刻对所有玩家触发一次。其中，角度变化按单方向累计，反向旋转时累计角度先归零再累计。

可用条件：

[思维导图-ef961c5bcff542a4a014dfbbbaafb655](#UWHYiUFGf5wMoPdFhXm7e2)

---
