# 阿赖耶识

分为创造版和生存版，创造版只能通过创造获得，并有强烈且不可逆的后果

### ***生存版***

***阿赖耶识-入鞘***

获得途径：？？？

伤害：6点 攻击速度：1.6

特殊功能：

*1.右键拔出，切换为出鞘形态（*需要特殊条件，目前还在考虑的有：

*需要15点生命上限，否则会显示：能力还不够使它出鞘
没了）*

*2.拿在主手或副手，每分钟会随机在下方选择效果生效*

随机选择一个遗忘，恢复为原物品

将2点被消除的血量上限复原

将2点被消除的饥饿度和饱腹上限复原

随机选择一个无我buff恢复为原buff

***阿赖耶识-出鞘***

伤害：14点 攻击速度：1.7

特殊功能：

*1.每次攻击造成伤害会随机在下方选择一个效果对自身生效*

将任意背包物品转化为：遗忘（包括盔甲，副手，但不包括武器本身）

将自身2点血量上限（一颗心）消除，被消除的血量上限转化为特殊的贴图（类似极限模式的心）

将自身2点饥饿度和饱腹上限消除，被消除的饥饿度上限转化为特殊的贴图（同上）

将任意自身的buff转化为：无我，继承原buff持续时间，但本身无任何效果

*2.每次攻击造成伤害会随机在下方选择一个效果对伤害的目标生效*

消除等同于本次伤害的血量上限（最低保留1点，每分钟恢复1点）

消除等同于本次伤害的护甲值（每分钟恢复1点，如果没有则变成消除血量上限）

消除等同于本次伤害的饥饿度和饱腹（最低保留6点，每分钟恢复1点，如果没有则同上）

*3.如果自身因为特殊功能1中的效果2，导致自身所有生命上限全被转化，会获得 真-无我buff 1分钟*

*4.每有一个无我buff，武器面板伤害+1*

*5.击杀目标后，敌人会变成纯白消失*

*6.右键入鞘，切换为入鞘形态*

### ***创造版***

***阿赖耶识-入鞘***

获得途径：创造标签页

伤害：6点 攻击速度：1.6

特殊功能：

1.右键拔出，切换为出鞘形态

***阿赖耶识-出鞘***

伤害：14点 攻击速度：1.7

特殊功能：

*1.每次攻击造成伤害会随机在下方选择一个效果生效*

将任意背包物品转化为：遗忘（包括盔甲，副手，但不包括武器本身）

将自身2点血量上限消除，不可逆

将自身2点饥饿度和饱腹上限消除，不可逆

将任意自身的buff消除，不可逆

*2.每次攻击造成伤害会随机在下方选择一个效果对伤害的目标生效*

消除等同于本次伤害的血量上限，不可逆

消除等同于本次伤害的护甲值，不可逆（如果没有则变成消除血量上限）

消除等同于本次伤害的饥饿度和饱腹，不可逆（如果没有则变成消除血量上限）

将随机一个物品删除，不可逆（如果没有则变成消除血量上限）

*3.如果自身因为效果2，导致自身所有生命上限全被消除，杀死自己，清除自身uuid*

*4.击杀目标后，敌人会变成纯白消失，世界上不会生成被击杀的生物，如果强制生成会被立刻删除*

*5.如果击杀的目标是玩家，那么将会直接ban掉玩家并清除uuid（ban需要管理权限才能解除）*

*6.右键入鞘，切换为入鞘形态*

附加物品

[遗忘](遗忘.md)
