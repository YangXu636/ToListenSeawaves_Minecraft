# 指令？（先别管）

指令只能同时存在一条，违反指令会产生一级业

指令存在时间限制，时间限制结束算作违反指令

每条指令的前面都会有着：致\[玩家名称\]，

示例：“致需氧，三个月内将指令制作完成”

###### 玩家独有的功能类

**说出**\[某条信息 / 某个物品的名称 / 某个玩家的名称 / 某个实体的名称\]

背包里有[神谕终端【双蛇杖】](神谕终端【双蛇杖】.md)时，有小概率将其替换为：**说出**\[[为爱痛苦而祈祷](https://libraryofruina.huijiwiki.com/wiki/%E4%B8%BA%E7%88%B1%E7%97%9B%E8%8B%A6%E8%80%8C%E7%A5%88%E7%A5%B7)的其中一段\]

**丢掉**\[背包中的某个物品（包括盔甲，快捷栏副手）\]

**合成**\[某个具有合成配方的物品（背包里的材料必须能够合成）\]

**食用**\[某个食物，药水之类能够吃的东西\]

**破坏**\[附近的某个方块（需要能被破坏）\]

**使用**\[背包里的某个物品（无论是左键还是右键都可以算作成功）\]
